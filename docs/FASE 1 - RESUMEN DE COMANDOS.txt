FASE 1 - RESUMEN DE COMANDOS:

:: Verificar PHP
php -v

:: Verificar Composer
composer --version

:: Verificar Node.js
node -v

:: Verificar npm
npm -v

:: Verificar MariaDB de XAMPP
C:\xampp\mysql\bin\mysql.exe --version

:: Entrar a htdocs
cd C:\xampp\htdocs

:: Ver contenido
dir

:: Crear específicamente proyecto Laravel 12
composer create-project laravel/laravel:^12.0 inventarios_vaai

:: Entrar al proyecto
cd inventarios_vaai

:: Verificar versión de Laravel
php artisan --version

:: Ver información del entorno
php artisan about

:: Levantar servidor de desarrollo
php artisan serve
